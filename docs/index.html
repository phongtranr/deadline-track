How it works

  1. GitHub Actions crawls official conference pages when the site deploys.
  2. The tracker extracts submission-related dates from visible page text.
  3. Future official dates are marked live.
  4. Missing or stale dates fall back to predictions from historical deadlines.

Predicted deadlines are planning aids and should be verified on the official conference website before making submission decisions.

Deadline data is generated by GitHub Actions and served as a static GitHub Pages site.
